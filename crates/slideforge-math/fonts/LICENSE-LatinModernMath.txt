Source:       https://www.gust.org.pl/projects/e-foundry/lm-math

Description:
Latin Modern Math is a math companion to the Latin Modern family of fonts
(lm-math). It provides mathematical symbols and alphabets for use in
mathematical typesetting with TeX and related systems.

Note on bundling in slideforge-math:
This font file is embedded verbatim in the slideforge-math crate as a static
byte array (`include_bytes!`) to enable pure-Rust PDF glyph outline rendering
without requiring a system font installation. The font is used unmodified; its
name has not been changed. In accordance with GFL clause 1, this is a
distribution (not a derivation), so no renaming is required. The license text
is preserved in this file alongside the font.
