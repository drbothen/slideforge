# HS-006: Brand Synthesis from Sparse brand.toml — Only 2 Colors Declared

## Objective

Validate DEC-016: the brand synthesizer infers all 12 OOXML color scheme slots from a
minimal brand.toml that declares only a primary and secondary color. The synthesized
palette must produce a visually coherent, accessible deck without requiring the user
to specify every slot.

## Scenario Description

A user with a simple brand identity (primary blue, secondary orange) creates the
minimal viable brand configuration:

**`sparse-brand.toml`:**
```toml
[colors]
primary = "#0057B8"
secondary = "#FF6B00"
```

No fonts, no accent colors, no background colors, no neutral colors are declared.

A 15-slide deck is built using this brand:
- Title and content slides (use primary color as heading accent)
- stat_callout slides (use secondary color for callout values)
- severity_cards slides with 3 severity levels (red/amber/green — must be inferred)
- Chart slide (uses accent colors for series)
- Light and dark themed layouts

## Expected Postconditions

1. `slideforge build sparse-deck.sf --format pptx` exits 0 (not a validation error).
2. A warning is emitted listing the 10 inferred color slots with their derived values.
3. All 12 OOXML theme color slots are populated in the output .pptx (no empty slots).
4. Severity colors (red/amber/green) are present and distinguishable — contrast ratio
   ≥ 3.0:1 against the background for each severity level.
5. The output .pptx is visually coherent in LibreOffice (not garbled or monochrome).
6. Font: Liberation Sans is used as fallback (warning emitted naming the fallback).

## Evaluation Criteria

| Criterion | Weight | PASS condition |
|-----------|--------|---------------|
| Build exits 0 | CRITICAL | Exit code 0 |
| Warning lists inferred slots | HIGH | Stderr/warning output names each inferred slot |
| All 12 slots populated | HIGH | No empty theme color slots in PPTX XML |
| Severity colors distinguishable | MEDIUM | Contrast ≥ 3.0:1 (automated check) |
| Font fallback warning | MEDIUM | Warning names Liberation Sans explicitly |

## Information Asymmetry Note

This is a non-must-pass quality scenario. The hidden test is that brand synthesis does
not FAIL on sparse input — it degrades gracefully with warnings. The evaluator checks
that a new user can provide just two brand colors and get a usable deck, not an error.
Specific inferred values are not asserted — only that the slots are populated and the
output is visually coherent.
