# Screen: First Run (SCR-009)

> **Sharded UX screen (DF-021).** Navigate via `UX-INDEX.md`.

## Purpose and User Context

The first-time user experience covers the path from installation to a successful
first build. The goal is: download binary → `slideforge init` → `slideforge build` →
working PPTX in under 2 minutes with no flags and no config file required.

Target user: a developer who just installed slideforge and wants to see it work.

---

## Elements

| ID | Type | Label | Notes |
|----|------|-------|-------|
| ELM-001 | `slideforge --version` | Version string | Confirms installation |
| ELM-002 | `slideforge init` | Scaffold output | Creates starter files |
| ELM-003 | Scaffold file list | Files created | With paths |
| ELM-004 | Next-step prompt | What to do next | Always shown after init |
| ELM-005 | `slideforge build deck.sf` | Standard build output | Per SCR-001 |

## Output Format Specification

### Version Check

```
$ slideforge --version
slideforge 1.0.0
```

### Init (no args — scaffolds in current directory)

```
$ slideforge init

Created slideforge project in /Users/you/my-deck/

  deck.sf          — main presentation source
  brand.toml       — brand configuration (edit with your colors)
  slideforge.toml  — project configuration
  assets/          — put images and data files here
  dist/            — output goes here (git-ignored)

Get started:
  slideforge build deck.sf             → builds deck.pptx
  slideforge watch deck.sf             → live preview at http://localhost:3000
  slideforge config explain deck.sf    → show all resolved settings

DSL reference: https://slideforge.dev/docs/dsl
```

### Init: Directory Already Has a slideforge.toml

```
$ slideforge init

error[E-CFG-008]: A slideforge.toml already exists in this directory.
  = hint: To reinitialize, remove slideforge.toml and run `slideforge init` again.
          Or run `slideforge init --force` to overwrite (CAUTION: destructive).
```

### Generated deck.sf Content

The scaffolded `deck.sf` must be immediately buildable with no modifications:

```
# Generated by slideforge init
# Edit this file to build your first deck

slideforge_version "1"

metadata:
  title "My First Deck"
  author "Your Name"
  lang "en-US"
  brand "brand.toml"

vars:
  topic "Getting Started"

slide title:
  title "{{ topic }}"
  subtitle "Built with slideforge"

slide content:
  title "What is slideforge?"
  bullets:
    - "A DSL for building branded presentations"
    - "PPTX, DOCX, PDF, HTML from one source"
    - "Live data reactive — connect @data sources"
  takeaway "Data-driven documents from structured source."

slide end:
  title "Questions?"
```

## Interactions

| ID | Trigger | Success Path | Error Path |
|----|---------|-------------|------------|
| INT-001 | `slideforge init` | Scaffold 4 files + assets/; print file list; print next-steps | E-CFG-008 if slideforge.toml exists |
| INT-002 | `slideforge init --force` | Overwrite existing scaffold; warn user | N/A (flag opts in to overwrite) |
| INT-003 | `slideforge init my-project` | Create `my-project/` directory, scaffold inside | E-EXP-007 if directory not writable |
| INT-004 | `slideforge build deck.sf` (after init) | Successful build with 3 slides; writes dist/deck.pptx | Should never fail on scaffolded deck |

## Accessibility

- File list formatted as readable plain text (no table borders)
- Next-steps section is numbered prose
- URLs are plain text (screen-reader safe; modern terminals auto-link)
- Scaffolded `deck.sf` includes `lang "en-US"` from day one (accessibility default)

| Width | Adaptation |
|-------|-----------|

| 60+ chars | Default layout |
