## Coverage Mapping

### AC-001: Well-formed HTML5

**Success path:** Fixture deck exported via `HtmlExporter::export()` produces bytes
beginning with `<!DOCTYPE html>`, and the DOM contains 3 `<article>` slide containers.

Evidence: `AC-001-html5-doctype-article.txt`, `AC-001-html5-structure.png`

**Error path:** Covered by Rust unit test `test_BC_4_03_003_export_starts_with_doctype_html`
(assertion fires if DOCTYPE missing) and `test_BC_4_03_003_article_container_present`
(assertion fires if no `<article>` exists).

---

### AC-002: `html[lang]` from deck lang

**Success path:** Deck with `lang: "en-US"` produces `<html lang="en-US">`. Deck with
`lang: "ja"` produces `<html lang="ja">`.

Evidence: `AC-002-html-lang-attribute.txt`

**Error path:** Unit tests `test_BC_4_03_003_lang_attribute_never_hardcoded_as_en`
and `test_BC_4_03_003_html_lang_attribute_matches_deck_lang_ja` explicitly assert
the hardcoded `lang="en"` anti-pattern is absent.

---

### AC-003/AC-005: SVG layer graphical frames — `role="img"` + `<title>`

**Success path:** Fixture HTML contains 2 `<g role="img" aria-labelledby="...">` elements
(one for the non-decorative image on slide 2, one for the diagram on slide 3). Each has
a `<title id="...">` child with the alt text. Outer `<svg>` elements have `role="presentation"`.

Evidence: `AC-003-005-svg-role-img-title.txt`

**Error path:** Unit tests `test_BC_4_03_003_non_decorative_image_has_non_empty_alt`,
`test_HIGH1_provided_alt_chart_regression_still_has_role_img_and_title`,
`test_HIGH1_invariant_no_role_img_with_empty_title_for_any_arm` cover the correctness
boundaries (non-empty alt required, no role="img" on empty title).

---

### AC-004: Decorative images — `aria-hidden="true"` in SVG layer

**Success path:** No bare `<img>` elements in the fixture output. Decorative `FrameContent::Image`
renders as `<g aria-hidden="true">` in the SVG graphics layer.

Evidence: `AC-004-decorative-image-aria-hidden.txt`

**Error path:** Unit tests `test_BC_4_03_003_decorative_image_has_empty_alt_and_role_presentation`,
`test_BC_4_03_003_ec_001_only_decorative_images_all_have_empty_alt`, and
`test_HIGH1_decorative_chart_uses_aria_hidden_not_role_img` verify the pattern.

---

### AC-006: P4 DOM structure

**Success path:** Fixture DOM has: `<canvas>` count = 0, `<foreignObject>` count = 0,
`<article>` count = 3 (one per slide).

Evidence: `AC-006-no-canvas-no-foreignobject-article.txt`, `AC-006-p4-dom-structure.png`

**Error path:** Unit tests `test_BC_4_03_003_no_canvas_elements_in_output`,
`test_BC_4_03_003_no_foreign_object_in_output`, `test_BC_4_03_003_article_container_present`
assert these properties. `test_F005_render_svg_chart_strips_foreign_object` verifies
`<foreignObject>` is stripped from embedded SVG content.

---

### AC-007: Zero WCAG AA violations via axe-core

**Success path:** `@axe-core/playwright` scanned the 3-slide fixture HTML with tags
`wcag2a` + `wcag2aa`. Result: **0 violations**, **18 passes**.

Evidence: `AC-007-axe-core-results.json`, `AC-007-wcag-aa-rendered-fixture.png`,
`AC-007-009-axe-core-wcag-aa-zero-violations.txt`, `FLOW-001-axe-core-browser-session.webm`

**Error path (CI gate):** The CI job `html-wcag-check` in `.github/workflows/html-wcag.yml`
runs the same axe-core check on every PR touching `crates/slideforge-html/**`. The job
exits non-zero if any violations are found.

### AC-008: Heading hierarchy — exactly one `<h1>`

**Success path:** Fixture deck (slide 1 is `slide_type = "title"` with a Title frame)
produces exactly 1 `<h1>` (slide 1 title "Fixture Presentation") and 1 `<h2>` (slide 1
subtitle "Exploring accessible document generation"). No level skips.

Evidence: `AC-008-heading-hierarchy-one-h1.txt`, `AC-008-heading-hierarchy.png`

**Error path (step 3):** Unit test `test_CRIT1_fixture_heading_order_no_level_skip`
verifies h1 before h2, no h3. Test `test_CRITICAL_B1_step3_body_text_promoted_h1_*`
verifies the warning path (no Title frame, first body slide promoted to h1).
Test `test_CRITICAL_B1_step4_synthetic_h1_*` verifies the synthesized visually-hidden
h1 on chart-only decks.

---

### AC-009: Body text contrast ratio

**Success path:** axe-core `color-contrast` rule PASSED in the same scan as AC-007.
The brand fixture uses `#003087` (primary, dark blue) on white — well above 4.5:1.

Evidence: `AC-007-009-axe-core-wcag-aa-zero-violations.txt` (line: `+ color-contrast: ...`)

**Error path:** Low-contrast brand colors are blocked at compile time by BC-5.01.003
before reaching the HTML exporter.

---

### AC-010: URL scheme allowlist (CWE-601)

**Success path:** The rendered fixture HTML contains zero `href="javascript:"` attributes.
The `is_safe_link_scheme()` function accepts `http`, `https`, `mailto`, `tel`, and
relative URLs. It rejects `javascript:`, `data:`, `vbscript:`, and protocol-relative `//`.

Evidence: `AC-010-url-scheme-allowlist-javascript-dropped.txt`

**Error path (security test):** Unit test `test_BC_4_03_003_javascript_href_dropped_in_export`
constructs a `LaidOutSlide` with a `Link` node whose URL is `javascript:alert(1)` and
asserts the rendered HTML contains no `href="javascript:"`. Test
`test_BC_4_03_003_rejected_scheme_emits_tracing_warn` confirms `tracing::warn!` is emitted.
Tests `test_F008_*` verify protocol-relative URL (`//evil.com`) rejection.
