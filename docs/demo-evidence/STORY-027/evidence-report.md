### AC-006: Manual supersedes auto when both present

**Traces to:** BC-3.02.001 precondition 3

**Test:** `sections::tests::test_ac_006_manual_executive_summary_supersedes_auto_generated_rewrite`

**What it proves:** When a `Deck` contains both `takeaway:` slides (which would produce
an auto-generated `ExecutiveSummary`) AND an explicit `section executive_summary:` block,
`collect_sections` suppresses the `SectionKind::ExecutiveSummary` auto-generated variant
and retains the `ManualSection("executive_summary")` with `source: ManuallyAuthored`. A
`tracing::warn!` lint is emitted (BC-3.02.001 EC-002). Exactly one executive-summary
section appears in the output.

```
PASS [   0.016s] slideforge-layout sections::tests::test_ac_006_manual_executive_summary_supersedes_auto_generated_rewrite
```

**Error path:** No error — supersession is a valid non-error outcome. The lint warning
is the diagnostic signal. Covered by `test_crit_002_supersession_warning_emitted_for_executive_summary`.
